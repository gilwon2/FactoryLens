# 오류 처리 예시 CSV (가상 데이터)

각 폴더의 `production.csv`와 `defects.csv`를 앱에 함께 업로드하면 아래 결과가 나와야 합니다.
파일은 `python scripts/make_invalid_examples.py`로 다시 만들 수 있습니다. 기대 결과는 `tests/test_invalid_examples.py`가 자동으로 확인합니다.

## 파일 단위 오류: 아무것도 적재하지 않음

| 폴더 | 내용 | 기대 결과 |
|---|---|---|
| `01_empty_file` | production이 0바이트 | "빈 파일입니다." |
| `02_missing_column` | `produced_qty` 컬럼 없음 | "필수 컬럼이 없습니다: produced_qty" |
| `03_header_only` | 헤더만 있음 | "헤더만 있고 데이터 행이 없습니다." |
| `04_wrong_column_count` | 5번 줄 값에 따옴표 없는 쉼표(`1,000`) | "5번 줄의 열 개수가 6개입니다" |

## 행 단위 오류: 정상 행만 적재

| 폴더 | 내용 | 생산 행 (원본 → 적재) | 불량 행 (원본 → 적재) | 이슈 |
|---|---|---|---|---|
| `05_bad_values` | 결측, 없는 날짜(09-31), `2026/09/02`, `12.5`, `-10` | 8 → 3 | 3 → 3 | 오류 5 |
| `06_duplicates` | L1 완전중복, L2 키 충돌, 불량 완전중복 | 5 → 2 | 4 → 2 | 경고 2, 오류 3 |
| `07_cross_check` | 없는 LOT(L9)의 불량, L4 불량 4 > 생산 3 | 4 → 3 | 6 → 3 | 오류 4 |

`06_duplicates`에서는 규칙이 연쇄로 적용됩니다. L2가 키 충돌로 제외되면 L2의 불량 행도 "유효한 생산 데이터에 없는 LOT"(X1)가 되어 함께 제외됩니다.

## 정상 처리되어야 하는 경계 사례

| 폴더 | 내용 | 기대 결과 |
|---|---|---|
| `08_cp949_korean` | CP949(EUC-KR)로 저장한 한글 값 | 한글이 깨지지 않고 적재 |
| `09_zero_production` | 모든 LOT의 생산량 0, 불량 파일은 헤더만 | 적재 성공, 불량률은 "-" 표시 |
